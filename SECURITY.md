# Security

Tech-Me is an instruction-only skill. It does not need credentials, network access, or runtime dependencies. Do not place secrets, customer records, internal repositories, or sensitive personal data in public evaluation scenarios.

The skill instructs agents to inspect only relevant non-secret project artifacts and to avoid unauthorized file edits, package installation, or deployments. Actual agent permissions are controlled by the hosting client; review them before use.

For a vulnerability or unsafe instruction, open a [GitHub issue](https://github.com/L4ncelotz/tech-me-skills/issues) without disclosing credentials or exploit secrets. If sensitive disclosure is required, use the repository's [private security advisory](https://github.com/L4ncelotz/tech-me-skills/security/advisories) feature after publication (if enabled).
